# 🔬 FoodFit 데이터 분석 인사이트

> 이 문서는 Google Trends API와 Open-Meteo 날씨 API를 활용한 음식-날씨 상관관계 분석 결과를 정리한 것입니다.

**분석 기간**: 2024년 1월 ~ 2025년 12월  
**분석 지역**: 서울, 부산, 대구, 광주, 대전  
**분석 방법**: 피어슨 상관계수, 다변량 회귀분석

---

## 📊 핵심 발견

### 1. "비 오면 파전"은 마케팅? 🤔

**분석 결과**:
| 변수 | 파전 상관계수 | 해석 |
|------|--------------|------|
| 강수량 | +0.06 | 거의 무관 |
| 기온 | +0.42 | 양의 상관 |

**결론**: 파전은 비보다 **따뜻한 날씨**와 더 강한 상관관계를 보임!
- "비 오면 파전"은 문화적 마케팅 효과가 강함
- 실제 검색 패턴은 기온의 영향을 더 크게 받음

---

### 2. 라떼 vs 아이스 아메리카노 ☕

**분석 결과**:
| 음료 | 기온 상관계수 | 최적 시즌 |
|------|--------------|----------|
| 라떼 | -0.41 | 겨울 (11~2월) |
| 아이스 아메리카노 | +0.75 | 여름 (6~8월) |

**결론**: 커피 선택은 날씨에 크게 좌우됨!
- 추운 날: 따뜻한 라떼 선호
- 더운 날: 시원한 아이스 아메리카노 선호

---

### 3. 예측력의 차이 📈

**더운 날 음식 (R² 0.70~0.83)**:
- 빙수: R² = 0.83
- 냉면: R² = 0.79
- 콩국수: R² = 0.75
- 아이스아메리카노: R² = 0.72

**추운 날 음식 (R² 0.20~0.30)**:
- 김치찌개: R² = 0.28
- 설렁탕: R² = 0.25
- 라면: R² = 0.22

**결론**:
- 더운 날 → "시원한 것" 하나로 수렴 (예측 쉬움)
- 추운 날 → 선택지 분산 (김치찌개, 설렁탕, 라면, 칼국수 등 경쟁)

## ⚙️ 알고리즘 적용

이 분석 결과는 FoodFit 추천 알고리즘에 다음과 같이 적용됩니다:

### 날씨 기반 가중치

```typescript
// 더운 날 (25°C+)
빙수: +25%, 냉면: +25%, 콩국수: +20%
국물요리: -15%, 라면: -10%

// 추운 날 (5°C-)
김치찌개: +20%, 설렁탕: +18%, 라면: +15%
냉면: -30%, 빙수: -30%

// 비 오는 날
파전: +5% (실제 영향 작음)
배달음식(치킨, 피자): +10%

// 습한 날 (70%+)
삼계탕: +15%, 빙수: +10%
```

### 지역 기반 보정

```typescript
// 부산 사용자
밀면: +30% (지역 특산물)

// 대전 사용자
냉면: +10% (기온 민감도 반영)
```

## 📈 향후 분석 계획

1. **사용자 데이터 축적**
   - FoodFit 앱 사용자의 실제 선택 데이터 수집
   - 날씨 + 기분 + 시간대 복합 분석

2. **메뉴 확장 분석**
   - 현재 ~130개 → 300개+ 메뉴 분석
   - 양식, 일식, 중식 세분화

3. **실시간 트렌드 반영**
   - GitHub Actions로 3일마다 자동 업데이트
   - 계절별 트렌드 변화 추적

## 📚 데이터 출처

- **검색 트렌드**: Google Trends API (2024~2025년 한국)
