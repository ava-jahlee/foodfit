# 🔬 FoodFit 데이터 분석 인사이트

> 이 문서는 Google Trends API와 Open-Meteo 날씨 API를 활용한 음식-날씨 상관관계 분석 결과를 정리한 것입니다.

**분석 기간**: 2024년 1월 ~ 2025년 12월  
**분석 지역**: 서울, 부산, 대구, 광주, 대전  
**분석 방법**: 피어슨 상관계수, 다변량 회귀분석

## 📊 핵심 발견

### 1. "비 오면 파전" - 드디어 증명됨! 🌧️🥞

**📊 Google Trends 일별 분석 결과 (2024년 366일 데이터)**:

| 조건 | 평균 검색량 | 변화율 |
|------|-----------|--------|

| **비 온 날 (107일)** | **11.2** | **+345.4%** 🔥 |

**🔄 Lag 효과 (시간 지연 효과)**:
- 비 오기 전날 → 당일: **+20.0%** 상승
- 비 온 당일 → 다음날: **-42.2%** 하락
- **의미**: 비 올 때만 폭발적으로 검색, 다음날 원래대로

**📅 주말 효과**:
- 평일: 3.6
- 주말: 8.6 (**+138.4%**)
- **의미**: 주말에 집에서 파전 부쳐 먹는 문화

**💡 데이터 분석 방법론**:
- **일별 데이터의 중요성**: 특정 날짜의 폭발적 변화를 정확히 포착
- **366일 전체 분석**: 통계적으로 유의미한 샘플 사이즈

**결론**: 
- **"비 오면 파전"은 실제로 존재하는 강력한 패턴!**
- 검색량이 3.5배 이상 증가하는 명확한 트렌드
- 주말 효과와 결합 시 더욱 강력

**🔍 요일별 상세 분석**:
| 요일 | 평균 검색량 | 특징 |
|------|-----------|------|
| 월요일 | 0.9 | **최저** - 주말에 이미 먹음 |

| 토요일 | 6.8 | 주말 효과 본격화 |
| **일요일** | **10.4** | **최고** - 주말 마지막날 |

**💡 인사이트**: 일요일 저녁이 파전 최대 수요 시간대!

### 2. 요일별 음식 패턴 📅

**금요일부터 시작되는 외식/배달 열풍**:
| 음식 | 월요일 | 금요일 | 토요일 | 주말 증가율 |
|------|--------|--------|--------|------------|
| 치킨 | 59.6 | 69.0 | 79.2 | +33% |
| 피자 | 54.0 | 63.1 | 73.9 | +37% |
| 막걸리 | 57.5 | 65.7 | 73.2 | +27% |

**주말 패턴**:
- **토요일**: 막걸리가 최고조 (집들이, 야외 활동)
- **일요일**: 파전, 삼계탕이 인기 (가족 식사)

**월요일 블루**:
- 대부분의 음식이 월요일에 최저치
- 특히 파전은 일요일 대비 **-91%** 급감!
- 간편식(라면, 김치찌개)만 비교적 유지

### 3. 라떼 vs 아이스 아메리카노 ☕

**분석 결과**:

- 추운 날: 따뜻한 라떼 선호
- 더운 날: 시원한 아이스 아메리카노 선호

### 3. 예측력의 차이 📈

**더운 날 음식 (R² 0.70~0.83)**:
- 빙수: R² = 0.83
- 냉면: R² = 0.79
- 콩국수: R² = 0.75
- 아이스아메리카노: R² = 0.72

**추운 날 음식 (R² 0.20~0.30)**:
- 김치찌개: R² = 0.28
- 설렁탕: R² = 0.25
- 라면: R² = 0.22

**결론**:
- 더운 날 → "시원한 것" 하나로 수렴 (예측 쉬움)
- 추운 날 → 선택지 분산 (김치찌개, 설렁탕, 라면, 칼국수 등 경쟁)

## ⚙️ 알고리즘 적용

이 분석 결과는 FoodFit 추천 알고리즘에 다음과 같이 적용됩니다:

### 날씨 기반 가중치

```typescript
// 더운 날 (25°C+)
빙수: +25%, 냉면: +25%, 콩국수: +20%
국물요리: -15%, 라면: -10%

// 추운 날 (5°C-)
김치찌개: +20%, 설렁탕: +18%, 라면: +15%
냉면: -30%, 빙수: -30%

// 비 오는 날
파전: +5% (실제 영향 작음)
배달음식(치킨, 피자): +10%

// 습한 날 (70%+)
삼계탕: +15%, 빙수: +10%
```

### 지역 기반 보정

```typescript
// 부산 사용자
밀면: +30% (지역 특산물)

// 대전 사용자
냉면: +10% (기온 민감도 반영)
```
